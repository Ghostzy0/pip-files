# Scope and next work

This alpha prioritises explicit, recoverable local folder operations. Future work is proposed, not shipped or scheduled.

- Close native reference, removable-volume, revoked-grant and assistive-tech evidence gaps.
- User-reviewed reconciliation of interrupted operations and retained recovery files.
- Safer rule import/export, grouped conditions and rename templates.
- Event-based watching and measured idle performance on larger folders.
- Recursive rules, cross-volume move and richer archive formats only after dedicated safety/metadata tests.

No cloud account, script/deletion rule, paid service or suite manager is required by this alpha.
