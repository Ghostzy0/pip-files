# Release notes

## Unreleased · experimental shared source

The source defines neutral Files Replica and Files Baseline Plus configurations alongside Pip Files and Pip Files Plus. Plus adds read-only History search, filters, and reviewed local JSON/CSV reports. Packaged variants use independent bundle and data identities. The older generic Files Baseline profile remains available for development reproduction.

This is a public source snapshot, not a binary release. On 23 October 2026, a local macOS 27.0.1 arm64 test run passed 50 active tests, with one expected child-helper skip and zero failures, on source/test inputs later byte-verified against public code commit `988769630e3a1d31a3046c0390801479cfccede3`; this was not a fresh-public-checkout test. On 24 October, a fresh public export at `988769630e3a1d31a3046c0390801479cfccede3` produced the custom `baseline-plus`, `pip`, and `pip-plus` candidates; the separate Replica candidate was built from `pip-files-replica` at `f5fa7edea79d984541c3efdfbe4af419d8e90e64`. Hosted macOS 14 CI independently passed tests and builds at exact custom code commit `988769630e3a1d31a3046c0390801479cfccede3` ([run 40117704192](https://github.com/Ghostzy0/pip-files/actions/runs/40117704192)). Current main merge `2e9aa59fac2f033b75778c4a8dd6a0cab01b3ccd` passed hosted CI ([run 40119435892](https://github.com/Ghostzy0/pip-files/actions/runs/40119435892)) and differs from the tested code commit only in `CHANGELOG.md` and `SOURCE-MANIFEST.json`. Native acceptance remains partial: bounded Plus report and minimum-window disclosure/error-layout checks passed, while current-source Core/Replica workflows, Neutral Plus Return activation ([issue #8](https://github.com/Ghostzy0/pip-files/issues/8)), and broader keyboard/accessibility acceptance remain open.
