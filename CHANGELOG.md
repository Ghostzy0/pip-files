# Changes

## Unreleased · experimental source integration
- Plus History now gives Save JSON an explicit initial focus target while retaining the Return default action and Escape cancellation. The experiment awaits native keyboard retest in Neutral Plus and Pip Plus; it does not establish a fix or acceptance. [Related issue #8](https://github.com/Ghostzy0/pip-files/issues/8).
- Dirty-rule quit and close confirmation now uses an owned AppKit alert sheet; Escape resolves to Keep Editing and close Discard continues after sheet dismissal. Native retest of this correction remains pending. [Related issue #13](https://github.com/Ghostzy0/pip-files/issues/13).
- The unsaved-draft confirmation now observes delegate state through a dedicated SwiftUI view modifier, addressing the reproduced missing-alert update. Direct native retest remains pending. [Related issue #13](https://github.com/Ghostzy0/pip-files/issues/13).

- Release packaging now uses SwiftPM's default backend with `-debug-info-format none` after both attempted backends stalled during `dsymutil` on this host. The root cause remains unknown; the earlier attempts produced no verified package. The Release script still performs stripping, local-path scanning, notice copying, signing, signature verification and atomic promotion. Debug builds remain available for diagnostics. Neutral Plus package and native acceptance remain pending. [Related issue](https://github.com/Ghostzy0/pip-files/issues/13).

- Neutral Plus now protects dirty inline rule drafts on app Quit and window close with a Keep Editing default/cancel action and explicit Discard Changes choice. Native retest of the exact Neutral Plus candidate remains pending; this source update does not establish acceptance. Related: [issue #13](https://github.com/Ghostzy0/pip-files/issues/13).

- Custom app bundles include the repository `LICENSE` and `THIRD-PARTY-NOTICES.md` under `Contents/Resources` before code signing. Pip Core, Pip Plus and Neutral Plus candidates were built from public-source head `8d094ec7729e3be983ea8d23ac5c1589fd28436f` on macOS 27.0.1 arm64. A fresh package restore on 25 October verified archive structure and CRCs, bundle identities, executable hashes and modes, source-matched notice bytes, and ad-hoc signatures with strict deep verification. This is package verification only: these exact candidates have not been run in the native GUI, and native acceptance and binary release gates remain pending. This makes no broader legal-compliance claim. See [issue #11](https://github.com/Ghostzy0/pip-files/issues/11).

- The neutral Replica preview now gives guidance that stays accurate before and after Apply: review proposed changes first; applied actions are recorded in History. This copy-only correction addresses [Replica issue #5](https://github.com/Ghostzy0/pip-files-replica/issues/5). A new native Move → Apply → History → Undo retest remains pending.

- The Plus export sheet keeps privacy disclosures and save errors in a bounded scroll region. At the minimum supported window, 24 October native visual checks of Pip Plus and Neutral Plus showed the full disclosures and all three controls in normal and refused-replacement states; refusal preserved the existing report bytes. Broader native and keyboard acceptance remains open. Neutral Plus Return activation remains under investigation in [issue #8](https://github.com/Ghostzy0/pip-files/issues/8); the layout change addresses the truncation reported in [issue #6](https://github.com/Ghostzy0/pip-files/issues/6).

Adds a neutral manual-informed view and editor shared by the `replica` and `baseline-plus` profiles, plus History search, filters and explicitly reviewed local JSON/CSV reports in the two Plus profiles. Core file-operation behavior is shared. Packaged editions use separate bundle and data identities, with edition isolation and packaged-path privacy checks. This is a source update, not a binary release. Current CI, native acceptance and release gates are tracked in [Testing](docs/TESTING.md). History count, empty-state, timestamp and issue captions now use stronger contrast in the reference layout and Core fallback; Plus report notices retain their edition palette.
