# Contributing

Build both editions and run `swift test --jobs 2` before a focused PR. Include a disposable reproduction for file safety changes. Keep preview free of writes, fail closed on collisions/identity changes, preserve per-action recovery and never add automatic personal-folder defaults. UI changes need actual native screenshots and keyboard/reduced-motion checks; document what was not tested.

No credentials, private journals, raw reference captures or copied competitor assets. Preserve MIT and update notices for new dependencies; no reserved Pip engine imports. Use GitHub issues for scoped defects and PRs for review. Do not run scripts or upload user files without explicit action/consent. Both Files Baseline and Pip Files must remain reproducible.
